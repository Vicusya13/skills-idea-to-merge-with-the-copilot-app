# Roadmap - Mona's Bookmark Manager

Plan for the next release of the bookmarks app.

## v0.2 - Next release

- **Delete a single bookmark** - add a Remove button to each row so users don't have to clear everything.
- **Search and filter** - filter saved bookmarks by URL or slug as you type.
- **Duplicate detection** - warn when a URL is already saved and show its existing slug.
- **Styled bookmark list** - card-style rows, slug badges and a visible focus state for keyboard users.

## Later

- Export and import bookmarks as JSON.
- Optional custom slugs (still prefixed with `mona-`).
